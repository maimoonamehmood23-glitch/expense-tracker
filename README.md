# Simple Expense Keeper

Build a simple, clean, modern and fully functional Personal Expense Tracker website.

Use only HTML, CSS, and JavaScript. Do not use any backend or paid services.

Design:

- Create a beautiful modern dashboard with a clean white and light-purple theme.

- Add a left sidebar with the title "Expense Tracker" and simple navigation.

- Add a "Total Expenses" card at the top showing the total amount dynamically.

- Add an "Add New Expense" form with:

  1. Expense Title

  2. Amount

  3. Category dropdown

  4. Add Expense button

- Categories should include Food, Transport, Shopping, Bills, and Health.

- Display all expenses in a clean responsive table.

- Each expense should show Title, Amount, Category, Date, Edit button, and Delete button.

- Use attractive SVG icons in the interface, including at least one clearly visible SVG icon.

- Add/Edit/Delete buttons should have clear icons.

- Make the website responsive for desktop and mobile.

Functionality:

- Add new expenses.

- Edit existing expenses.

- Delete expenses.

- Calculate and update Total Expenses automatically whenever an expense is added, edited, or deleted.

- Save expenses in localStorage so they remain after refreshing the page.

- Add category filtering.

- Show a friendly empty-state message when there are no expenses.

- Validate the form so title, amount, and category cannot be empty.

- Use JavaScript for all interactive functionality.

Important:

- Keep the design simple and professional.

- Make sure every button actually works.

- Test all functionality before finishing.

- Create all required files in the current project folder.
